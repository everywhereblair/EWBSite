# Notes for AI agents working on this repo

- **Content** lives in `src/content/{writing,projects,pages}/*.md` and is generated by `scripts/publish.mjs` from an Obsidian vault. Don't hand-edit it; change the source note and re-upload.
- **Loader:** `src/lib/server/content.ts` (gray-matter + marked). Routes: `/writing/[slug]`, `/projects/[slug]`, `/about`, each with a `.md` twin. Agent-readable outputs: `llms.txt`, `llms-full.txt`, `rss.xml`, `sitemap.xml`.
- **Everything is prerendered** (`src/routes/+layout.ts`). The build fails on broken internal links: keep it that way.
- **Publisher:** pure transforms in `scripts/lib/transform.mjs` with tests in `scripts/transform.test.mjs`. Run `npm run test:publish` after changing either.
- **Design constraints:** easy navigation (3 top-level sections, everything within 2 clicks), one readable column (~68ch), no infinite scroll, table of contents on long articles. Theme tokens live in `src/app.css`.
- **Public repo.** Never commit drafts, vault paths, or anything confidential. `scripts/publish.local.json` is gitignored.
