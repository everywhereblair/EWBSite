# EverywhereBlair

A personal site built with SvelteKit, Tailwind CSS v4, and deployed to Cloudflare Pages. Features the Nordblau Metallic dark theme with a serif/sans typography pairing inspired by Eigenwise.

## Setup

```sh
npm install
npm run dev
```

## Building

```sh
npm run build
```

Deploy to Cloudflare Pages via GitHub integration.
